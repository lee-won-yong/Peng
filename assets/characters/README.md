# 캐릭터 퍼즐

`character.png`는 1010 × 1557 픽셀의 캐릭터 시트입니다.
퀴즈마다 캐릭터 하나를 무작위로 고르고 2열 × 5행, 총 10조각으로 가립니다.
저장에 성공한 정답마다 아직 가려진 조각 하나를 무작위로 공개합니다.
오답과 저장 실패는 조각을 공개하지 않습니다. 다시 도전하면 새 퍼즐로 시작합니다.

`lib/character_puzzle.dart`의 `CharacterRegion`이 원본 좌표를 관리합니다.
왼쪽 여백 144px을 제외한 8열(각 96.75px), 행 높이 98px을 기준으로
캐릭터와 이름을 함께 표시하며 마지막 행은 이미지 끝에 맞춰 높이를 줄입니다.
행별 실제 캐릭터 목록만 등록하여 빈 칸과 흰 여백이 뽑히지 않게 합니다.
다른 배치의 시트로 교체하면 좌표와 행별 목록도 함께 수정해야 합니다.
