# 칭찬 캐릭터 이미지

정답을 맞추면 이 폴더의 캐릭터 PNG가 팝업으로 등장해 칭찬합니다.

## 사용법
아래 이름으로 투명 배경 PNG를 넣으면 자동으로 사용됩니다 (정사각형 권장, 256~512px):

- `brawl1.png`
- `brawl2.png`
- `brawl3.png`
- `brawl4.png`
- `brawl5.png`

파일이 없으면 이모지(🐻 🦊 ⭐ 🔥 🎯)로 자동 대체됩니다.
개수는 1개만 넣어도 되고, 넣은 파일만 표시됩니다(없는 번호는 이모지 폴백).

> 참고: 브롤스터즈 캐릭터는 Supercell의 저작물입니다. 비공개·개인 학습 용도로만 사용하세요.
